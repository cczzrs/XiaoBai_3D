# 小白 3D · 角色工作台

基于「创建参考图宠物 (4)」的批准结果，分为两个工作模块。原项目资源仅复制到本项目，原目录未改动。

## 启动

在项目目录执行：

```sh
./dev.sh
```

用外部 Chrome 打开 <http://127.0.0.1:8790>。端口占用时运行 `./dev.sh --port 8791`。必须通过 HTTP 访问，不能直接双击 HTML。依赖已放入 `vendor/`，运行不需要 npm 安装、CDN、API 密钥或网络服务。

## 01 · 3D 模型构建

- 已批准头部 `head-v1`：包含头、双眼和鼻子。
- 已批准身体 `body-v7`：完整身体，左右、前后对称。
- 两个原始 GLB 的 SHA-256 与原审批记录一致，直接沿用原世界坐标装配。
- 手臂、腿脚保留候选槽位，可导入独立 GLB 或 OBJ、单独查看、控制显示、移除候选。
- 正面、右侧、背面、左侧和透视视角；网格、线框、拖动旋转、滚轮缩放。
- 头部八视图中的四个正交视图、身体 TIFF 第 1 帧及辅助侧背视图、最后一个手臂动作参考，使用原配准叠图。自由旋转到不匹配的角度时暂停叠图。
- 保留原批准的黑色背景、默认无定向光。方位、仰角和强度可临时调整并恢复。

候选导入沿用文件的原始坐标和单位，应在云端建模交付时与现有 H100 坐标一致。导入入口不生成新网格、不自动改变头身基线、不将候选标记为批准。OBJ 不加载外部 MTL；GLB 需内嵌缓冲区与纹理。上限默认 50 MiB、200 万顶点、256 个网格、1000 坐标单位包围盒对角线。已带动画或蒙皮的文件不适用于当前静态部件入口。

## 02 · 形体、骨骼和姿态动作设计

- **形体**：头部整体比例，身体宽度、高度和厚度。设计变换应用到独立副本，切回构建模块显示批准比例。
- **骨骼**：Root → Body → Neck → Head 四个实际 Bone 节点；根关节、颈关节高度可调；骨骼显示可开关。
- **姿态**：头部左右转向、抬低头、侧倾，身体侧倾。
- **动作**：点头、摇摆、呼吸，速度与幅度可调；支持播放、暂停、时间轴定位和重置。

当前骨骼为部件刚性父子变换草稿，尚未做连续表面蒙皮；手臂与腿脚没有独立运动关节。设计草稿不是对外形修改的再次批准。后续可在部件批准后扩展四肢关节、蒙皮与动作。

## 保存与导出

- **保存草稿**或 `⌘ S` / `Ctrl S`：保存到当前浏览器的 localStorage；刷新后恢复设计参数和候选。容量不足会提示使用 JSON 导出，不会覆盖原文件。
- **项目 JSON**：保存形体、关节、姿态和动作参数，并嵌入候选文件内容；在「打开项目」中完整恢复。恢复后暂停播放。批准头身固定引用项目内原件。
- **模型 GLB**：导出当前模块、当前可见部件和当前姿态。设计副本带关节层级，但没有蒙皮权重和动画关键帧；动作参数保存在项目 JSON。
- **视口 PNG**：仅导出三维画面，不包含参考叠图、工具栏和检查面板。

相机、显示开关、光照、参考选择和叠图透明度是临时评审状态，不写入项目草稿。模型或项目文件先解析并验证，成功后才替换现有候选；项目内任意一个候选失败会保留原有整个装配。

## 文件结构

```text
index.html                 页面结构、模块和控件
styles/studio.css          布局、颜色、响应式外观
src/config.js              冻结的树形默认配置及数值范围
src/app.js                 模块、控件、保存导出交互
src/scene.js               三维场景、草稿骨骼与动作
src/model-io.js            模型解析、验证和 GLB 导出
src/project-state.js       项目格式、验证、候选编码与恢复
src/references.js          参考图裁切与世界坐标叠图
assets/approved/           已批准模型原件与审批记录
assets/references/         原始参考图片和配准数据
assets/manifest.json       来源、审批与哈希清单
vendor/                    Three.js r186 与许可证
scripts/serve.py            仅监听本机的静态服务器
qa/                        本次 Chrome 验证证据
```

HTML 保留固定页面结构，CSS 管理样式；JavaScript 只绑定控件、更新文本/状态及绘制 3D/参考画布，不用字符串生成页面或注入样式。数值默认值和范围统一在 `APP_CONFIG` 中。
