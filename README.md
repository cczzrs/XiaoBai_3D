# 小白 3D · 角色工作台

基于「创建参考图宠物 (4)」的批准结果，分为两个工作模块。原项目资源仅复制到本项目，原目录未改动。

## 启动

在项目目录执行：

```sh
./dev.sh
```

用外部 Chrome 打开 <http://127.0.0.1:8790>。端口占用时运行 `./dev.sh --port 8791`。必须通过 HTTP 访问，不能直接双击 HTML。依赖已放入 `vendor/`，运行不需要 npm 安装、CDN、API 密钥或网络服务。

## 01 · 3D 模型构建

- 已批准头部 `head-v1`：包含头、双眼和鼻子。
- 已批准身体 `body-v7`：完整身体，左右、前后对称。
- 两个原始 GLB 的 SHA-256 与原审批记录一致，直接沿用原世界坐标装配。
- 手臂、腿脚保留候选槽位，可导入独立 GLB 或 OBJ、单独查看、控制显示、移除候选。
- 正面、右侧、背面、左侧和透视视角；网格、线框、拖动旋转、滚轮缩放。
- 头部八视图中的四个正交视图、身体 TIFF 第 1 帧及辅助侧背视图、最后一个手臂动作参考，使用原配准叠图。自由旋转到不匹配的角度时暂停叠图。
- 默认黑色背景、无定向光。背景与灯光设置在两个模块共用，并随项目保存。

候选导入沿用文件的原始坐标和单位，应在云端建模交付时与现有 H100 坐标一致。导入入口不生成新网格、不自动改变头身基线、不将候选标记为批准。OBJ 不加载外部 MTL；GLB 需内嵌缓冲区与纹理。上限默认 50 MiB、200 万顶点、256 个网格、1000 坐标单位包围盒对角线。已带动画或蒙皮的文件不适用于当前静态部件入口。

## 02 · 形体、骨骼和姿态动作设计

- **形体**：头部整体比例，身体宽度、高度和厚度。设计变换应用到独立副本，切回构建模块显示批准比例。
- **骨骼**：Root → Body → Neck → Head 四个实际 Bone 节点；根关节、颈关节高度可调；骨骼显示可开关。
- **姿态**：头部左右转向、抬低头、侧倾，身体侧倾。
- **动作**：点头、摇摆、呼吸，速度与幅度可调；支持播放、暂停、时间轴定位和重置。
- **五官 → 眼睛**：宽度、高度、双眼间距、上下位置、目光偏移、左右眼独立开合；双眼眨眼、左眼眨动、右眼眨动、环顾。左右以正面画面为准。开合与目光只改变眼睛内部亮区，外侧轮廓保持固定；宽高、间距和位置仍是独立的外形参数。
- **五官 → 表情**：自然、可爱、开心、愤怒、思考、惊讶、困倦，表情强度可调。通过内部亮区的弯曲、倾斜、大小和不对称表达情绪，不新增瞳孔或改变眼睛外轮廓。强度为 0 保留基础眼神；与眨眼、环顾和其他动作叠加。
- **五官 → 鼻子**：宽度、高度、上下位置、鼻尖突出、倾斜；支持轻摆和宽度伸缩。
- 眼睛、鼻子和身体的动作可组合，共用播放速度与四秒时间轴，各有独立动作幅度。五官幅度 0 保持静态；静态参数与动作叠加后的值会限制在配置范围内。
- 「面部特写」放大查看五官；「恢复眼睛默认」「恢复鼻子默认」分别恢复该部件及其动作，恢复眼睛同时恢复自然表情。「恢复自然表情」只清除表情预设，保留眼睛基础参数。「重置姿态」重置身体姿态、眼神与开合、表情预设、鼻子倾斜和全部动作，保留五官形体比例与位置。
- **色彩皮肤**：头部、身体、眼睛、鼻子、手臂、腿脚分别设置颜色、粗糙度与皮肤图片。修改颜色或导入图片自动启用自定义材质；取消启用可暂时对照原材质，恢复按钮清除该部位的自定义设置。尚未导入的四肢可先保存外观，模型导入后应用。

五官变形只作用于设计副本的独立几何，使用原头部前表面采样保持贴合。闭眼只把内部亮区收拢为细弯缝，保留外侧眼环；鼻尖突出保持鼻根贴面。极端参数接近头部轮廓时会向可用表面收拢；独立参数不自动消除五官之间的重叠。默认值与重置可逐顶点恢复原五官。

当前骨骼为部件刚性父子变换草稿，尚未做连续表面蒙皮；手臂与腿脚没有独立运动关节。设计草稿不是对外形修改的再次批准。后续可在部件批准后扩展四肢关节、蒙皮与动作。

## 材质、背景和光照

- 皮肤和背景接受静态 PNG、JPEG、WebP，每张最多 8 MiB、单边 4096 像素。先校验格式和尺寸，再实际解码；坏图片不会替换当前内容。图片嵌入项目 JSON，不依赖原磁盘路径。
- 导入皮肤时调色设为白色以显示原图色彩；之后颜色与贴图相乘。粗糙度越小，高光越集中。材质仅应用于设计副本，构建模块保持原批准材质。
- 批准模型没有 UV。设计副本使用原始正面 XY 坐标投影，图片按比例居中裁切；贴图随形体和五官动作变形。侧面会有压缩，背面沿用同一投影；它不是完整的手工 UV 展开。已有 UV 的导入模型沿用原 UV。
- **背景设置**位于右侧：纯色、导入图片、等比铺满（裁切）或完整显示（留白）。透明区域和留白显示所选背景颜色；不拉伸图片。
- **视口光照**按指定 `head-v1/head-review.js` 及配置实现：启用定向柔光后关闭强均匀环境光，使用 9 束柔光主光、半球环境光、补光和轮廓光。方位、高度、主光强度及曝光可调，方向相对当前相机；关闭后恢复均匀光。没有新增地面或投影阴影。

## 保存与导出

- **保存草稿**或 `⌘ S` / `Ctrl S`：保存到当前浏览器的 localStorage；刷新后恢复设计参数和候选。容量不足会提示使用 JSON 导出，不会覆盖原文件。
- **项目 JSON**：保存形体、关节、姿态、动作、表情及强度、材质、背景和光照，并嵌入候选模型及图片；在「打开项目」中完整恢复。恢复后暂停播放。批准头身固定引用项目内原件。整份项目最多 256 MiB。
- 当前项目 revision 为 4；旧 revision 1、2、3 草稿与 JSON 校验后补入缺少的中立眼鼻、默认外观或自然表情，保留原参数和候选部件。保存时写入 revision 4。旧草稿的开合和目光数值沿用，渲染使用新的眼睛内部变化方式。
- **模型 GLB**：导出当前模块、当前可见部件和当前姿态。设计副本包括实际材质颜色、粗糙度及内嵌皮肤纹理；带关节层级，没有蒙皮权重和动画关键帧。背景图片、光照和可编辑动作通过项目 JSON 恢复，GLB 不包含场景背景或灯光对象。
- **视口 PNG**：仅导出三维画面，不包含参考叠图、工具栏和检查面板。

相机、显示开关、参考选择和叠图透明度是临时评审状态，不写入项目草稿。模型和图片先解析并验证，全部成功后才替换项目；任意候选模型或图片失败会保留原装配与外观。

## 文件结构

```text
index.html                 页面结构、模块和控件
styles/studio.css          布局、颜色、响应式外观
src/config.js              冻结的树形默认配置及数值范围
src/app.js                 模块、控件、保存导出交互
src/scene.js               三维场景、草稿骨骼与动作
src/face-rig.js            眼鼻副本形变、贴面与表情动作采样
src/appearance.js          材质、贴图、背景及参考柔光实现
src/image-io.js             图片格式、尺寸校验与解码
src/model-io.js            模型解析、验证和 GLB 导出
src/project-state.js       项目格式、验证、候选编码与恢复
src/references.js          参考图裁切与世界坐标叠图
assets/approved/           已批准模型原件与审批记录
assets/references/         原始参考图片和配准数据
assets/manifest.json       来源、审批与哈希清单
vendor/                    Three.js r186 与许可证
scripts/serve.py            仅监听本机的静态服务器
qa/                        本次 Chrome 验证证据
```

HTML 保留固定页面结构，CSS 管理样式；JavaScript 只绑定控件、更新文本/状态及绘制 3D/参考画布，不用字符串生成页面或注入样式。数值默认值和范围统一在 `APP_CONFIG` 中。
