## 连续网格的绑定方式

v6 不再包含两份独立腿网格，也不使用 v2 接环顶点索引生成权重。新绑定在模型坐标中计算连续的空间权重，给同一身体与双腿网格添加 `skinIndex`、`skinWeight` 和绑定矩阵；中立顶点、法线、三角面、材质和外形源文件保持原样。

每个顶点最多使用四个影响：身体骨、左踝骨、右踝骨，以及所在侧的膝骨。左右踝都沿各自髋→膝→踝骨链运动，所以髋、膝的动作角度照常传递，不通过缩小关节角度掩盖变形。少量直接膝骨影响帮助上腿跟随屈曲；它在脚部、上躯干和左右切换的中心处平滑归零。

空间权重使用两端一阶、二阶导数归零的五次平滑函数，使身体与腿之间以及中央左右分配连续。当前配置集中在 `APP_CONFIG.design.bindingV6.weights`：

| 配置 | 值 | 作用 |
| --- | ---: | --- |
| `bodyFreeY` | 13.447979927062988 | 此高度及以下保留区不分配身体权重，整足由所属踝骨链作刚性运动 |
| `bodyFullY` | 40 | 此高度及以上全部跟随身体骨 |
| `centerHalfWidth` | 5 | 中央左右分配在 X=-5 到 X=5 之间平滑变化，避免中央固定脊线 |
| `kneeContribution` | 0.1 | 腿部剩余影响中的直接膝骨辅助项，上限受纵向和侧向平滑系数共同约束 |

权重存储时以 `2²⁴` 为分母量化，并将舍入差归入最大影响项，使 Float32 权重和精确等于 1，避免中立姿态出现微小缩放漂移。身体与脚腕间较宽的过渡用于分散短粗腿屈曲时的变形；这会改变姿态中的软组织形变，但不改中立外形。

实现新增于 `web/src/limb-rig-v6.js`、`web/src/fused-leg-skinning.js` 和 `web/src/action-export-v6.js`。原 `limb-rig.js`、`action-motion.js`、`action-export.js` 保持原字节；v6 动作导出复用旧动作定义，再补充当前绑定版本及待确认状态。

## 使用与版本边界

点击形体设计页的“使用腿部 v6 绑定副本”，载入中立设计副本。身体和双腿共用显示开关及“腿脚皮肤”，设计模式隐藏独立身体副本；构建模式继续显示批准 body-v7 原件。

身体单独的宽、高、厚缩放继续锁定，以保持已认可的联合外形。身体侧倾与髋、膝、踝关节可在设计副本中检查。关节位置、转角、动作参数及版本选择随项目 JSON 保存。回到中立姿态可检查保留外形。

动作页提供步行、小跑、招手、思考和坐姿，沿用原有动作定义和可调参数，在 v6 绑定上检查效果。沿用批准动作参数不代表新绑定下的变形效果已经批准。完整动作导出需载入并显示 v59 双臂和已绑定双腿；缺少部件时导出按钮不可用，并显示原因。

v6 动作下载文件名为 `xiaobai-legs-v6-actions-design.glb`。旧 v5 保留为静态融合对照，继续锁定身体姿态与动作；v4、v3 和已批准 v2 入口保留。新建项目默认仍为 v2，不自动替换已保存项目。

旧版“呼吸起伏”通过独立身体缩放实现，不适用于身体与腿共用网格，v6 不提供该项。步行、小跑、招手、思考、坐姿这五个主要动作正常接入。
