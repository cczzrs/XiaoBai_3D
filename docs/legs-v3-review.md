# 腿脚 v3：圆弧与环线优化 · 待确认

本轮形成独立设计资产 `assets/design/legs-v3/legs.glb`，没有改写头部、身体、双臂、腿脚 v2、绑定、动作及其历史审批记录。v3 只交付静态形体，尚未绑定，外形待用户确认。

三项调整：

1. 保留脚掌至脚尖最宽处的原轮廓公式，从脚尖向脚面改用匹配位置、切线和曲率的连续曲线，收顺原脚背的肩状转折。
2. 脚部、膝盖以上腿根和隐藏圆顶统一按平均曲面行程采样，目标环距为 0.24 模型单位；最终 GLB 实测每圈平均间距为 0.239606–0.240966。这里指每一圈沿 160 条母线的平均间距，各条母线的局部间距会随腿根形状变化。
3. 保留与 body-v7 的非水平接合圈，将其内部封口改为 74 段圆顶过渡，末端水平切线收至顶部，取代原来单圈内缩后的尖锥封口。

模型包含镜像双腿，共 64,644 个顶点、129,280 个三角形。参数位于 `APP_CONFIG.design.legRefinementV3`；历史输入从已锁定的 v2 参数及接合数据只读取得。运行 `node scripts/build-legs-v3.mjs` 只重建到 `temp/generated/legs-v3/`，不会覆盖交付模型。

进入形体设计页，点击“查看腿脚 v3 优化副本”可切换到中立静态侧面特写；原 v2 按钮仍可切回批准版本。新拓扑不沿用 v2 的顶点编号权重。静态 GLB 导出区分当前不完整绑定与已批准绑定基线，原动作导出的完整绑定检查继续生效。
