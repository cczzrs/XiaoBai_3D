# 腿部 v8：前后对称的独立双腿

用户再次强调前后对称。检查确认 v7 腿身和顶部沿用了向后偏移的融合外壳，违背了该要求。本轮以原脚的中面 Z=4 为固定对称面，重建脚腕以上的整段腿身，而非仅移动顶部。

## 形体约束

- 左右腿为两个独立网格，并各自导出单件。
- 每条腿前 15,041 个脚部顶点、法线和 29,920 个面保留原数据。
- 脚腕到腿顶的截面中心固定在 Z=4；前后共享椭圆半径函数，上部面片和法线成对镜像。
- 顶部采用连续椭圆圆顶，按弧长均匀采样；脚腕沿用 v6 的曲率衰减，避免短距离内突变。
- 身体接合曲面保存在新的配套设计副本中。批准 body-v7 原件、已有版本和审批记录不覆盖。

脚部继承法线本来存在约 0.000433 的前后镜像微差。本轮优先保留用户认可脚部的原法线字节，不为了法线数值镜像而重算脚部。

## 验证

专项测试 `node --test tests/legs-v8.test.mjs` **13/13 通过**，详见 [独立验证摘要](../temp/legs-v8/validation-summary.md)与[完整报告](../temp/legs-v8/independent-v8-geometry-check.json)。

- 前后对应点最大误差 `4.768e-7`，新上部法线镜像误差为 0；新上部三角面也有对应反射面。
- 两腿各 30,242 个顶点、60,480 个三角形，独立闭合且左右镜像；脚部位置、法线、索引字节完全保留。
- 配套身体与两脚的 320 个边界点，位置和法线完全相同。内部下盖均在脚内。独立腿上部的顶点与面心采样全部满足原定 0.002 容差；侧切线候选经真实三角面距离复核，最大为 0.0009789。这是采样范围的结果，不等于证明任意姿态都没有全局自交。
- 为覆盖两套独立三角化的弦面误差，身体下部设计表面加最大 0.004 的微量外包络；升起高度为 1.2，17–20 高度间淡出。两端采用五次平滑函数，脚环、独立双腿和上部身体原表面保持不变。脚腕变化率跳变最大 1.8617、RMS 1.0427，均满足此前的 3 / 2 限值；身体衔接的法线与几何平滑指标也通过。
- 完整绑定和动作文件为 9 网格、5 蒙皮、20 骨骼、5 动作片段；与设计资产的几何字节一致。79 个动作采样时刻的接缝位置误差最大 `3.55e-15`，法线误差 0，脚部保持刚性。
- 26 个批准资产及历史实现锁定条目校验通过。旧 v2/v6 在新绑定引擎上的兼容专项 8/8 通过；本轮未运行全流程回归。
