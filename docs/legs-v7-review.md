# 腿部 v7：恢复独立左右腿

用户指出腿部应像 v4 一样由两个独立腿模型组成。v5/v6 为消除接缝，把身体与双腿融合成单个网格，这不符合所需部件结构。本次恢复独立身体副本、左腿和右腿，旧版资产及历史批准记录保留。

用户进一步明确“顶部不要是锥形，椭圆形可以”。独立腿顶采用圆润的椭球穹顶，顶部以水平切线收圆，不能出现锥尖或帽圈；脚部保持不变。

## 模型结构

- `assets/design/legs-v7/legs.glb` 仅包含 `Leg_L`、`Leg_R` 两个独立网格。
- `leg-left.glb`、`leg-right.glb` 分别提供单条腿。
- `body.glb` 为单独的身体设计副本，不混入腿脚文件。
- 配套身体由 v7 腿脚版本确定加载。工作台可分别显示身体和双腿；构建模式仍显示批准的 body-v7 原件。

v7 以已认可的 v6 可见曲面为来源，沿腿根斜平面分成三个部件。穿过分界线的三角面在原面内部细分，交点及法线由原面插值，三件的外壳合起来仍覆盖原可见曲面；脚部的原顶点和面完全保留。使用平整的分界线，可以避免沿锯齿边缘封口产生局部回折。新封口向装配内部延伸，但边缘存在下文记录的微小数值外露，不能称为严格完全内藏。新的内部封口及拆件结构属于本次设计调整，不把 v6 外形认可扩大成对新结构或新绑定的批准。

腿顶以椭球穹顶为主体，用原表面法线梯度的局部曲率拟合接续腿身；边界修正在顶部的位置、一阶和二阶导数均归零。每条腿的封顶有 52 道弧长环，平均间距约 0.3484，顶端不是锥母线。每条独立腿共 69,914 个顶点、138,336 个面。

## 绑定与导出

三个独立身体/腿网格共用既有骨架，并按相同模型空间规则计算权重。接缝两侧的位置、法线和权重保持一致，使拆件后的动作边界仍能同步。脚部保持刚性；中立外形和批准身体原件不被写回。

完整角色包含 9 个网格、5 个蒙皮和 20 根骨骼。五个既有动作继续沿用原定义及参数；v7 的拆件、内部封口和变形效果标记为待确认。

配置位于 `web/src/config.js`，新生成脚本只向 `temp/generated/legs-v7/` 和 `temp/generated/rig-v7/` 写入过程产物。正式设计副本单独保存在 `assets/design/legs-v7/` 和 `assets/design/rig-v7/`。本轮不覆盖批准资产或历史 QA，不执行 Git 提交。
