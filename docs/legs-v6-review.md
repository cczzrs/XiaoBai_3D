# 身体与腿 v6：身体接缝与脚腕圆润过渡 · 待确认

用户指出 v5 的身体与腿衔接处、脚腕处仍各有一圈轻微的明暗折痕，要求继续调整为自然、连续、圆润的弧面，同时保持脚部不变、不修改批准身体原件。

本轮候选路径为 `assets/design/legs-v6/body-legs.glb`，版本标识为 `body-legs-fair-v6`。它沿用身体与双腿联合设计副本的展示方式，当前外形待确认、尚未绑定。v5 保留用于对比，不覆盖原 v5 资产或其评审记录。

## 页面与资产边界

在形体设计页点击“查看身体与腿 v6 圆润副本”，进入中立静态正面特写。设计模式显示联合身体与腿，隐藏原独立身体副本；构建模式继续显示批准身体原件。“显示身体与腿”控制整个联合副本。切换 v5、v4、v3、v2 的入口保留，版本记录随项目 JSON 保存和恢复。

联合副本载入时恢复原比例、中立姿态并停止动作。身体宽、高、深及躯干动作暂不可单独调整，避免联合模型错位；统一颜色和纹理通过“腿脚皮肤”调整。v6 不复用 v2 顶点权重，不提供动作 GLB 导出。

静态导出的 `designSources.bodyAndLegs` 记录实际候选版本，状态为 `pending`、`skinning: false`。批准身体来源另记在 `preservedApprovedBaselines`，不作为当前融合身体的批准依据。`rigApproval` 为 `incomplete-design-copy`；原绑定和动作定义继续作为历史基线保留。

头部 head-v1、身体 body-v7、v59 双臂、legs-v2、rig-v1、actions-v1 与历史审批记录均不作为本轮编辑对象。临时生成、诊断、导出与截图写入 `temp/legs-v6/` 或 `temp/generated/legs-v6/`，不覆盖 `docs/qa/` 历史证据。
